# فراهوش وب — نسخه نهایی v16.12

این بسته برای اجرای نسخه وب فراهوش آماده شده است.

## اجرا

روی ویندوز:

1. فایل `start_frahoosh.bat` را اجرا کنید، یا در ترمینال:
   `python run_web.py`
2. سپس مرورگر را روی `http://127.0.0.1:5000` باز کنید.

## ورود مدیر

- نام کاربری: کد ملی مدیر
- رمز پیش‌فرض این نسخه: حرف اول نام + کد ملی
- حساب تست مدیر: `0053409531`
- رمز تست: `h0053409531`

## تنظیم نام مدرسه و سال تحصیلی

فقط فایل `config.py` را ویرایش کنید:

- `SCHOOL_NAME`
- `ACADEMIC_YEAR`

متن‌های ثابت برند و پشتیبانی در همان فایل نگهداری شده‌اند.

## ویژگی‌های این بسته

- ۱۳ پنل و ۱۰۹ ماژول ثبت‌شده در رجیستری وب
- نمایش فارسی نام پنل‌ها، ماژول‌ها، جداول و ستون‌های شناخته‌شده
- دکمه واقعی «بازگشت به صفحه قبل» در صفحه هر پنل و هر ماژول
- پرداخت آنلاین فقط با گزینه «اتصال به درگاه شاپرک» و بدون فرم شماره کارت
- دیتابیس SQLite همراه پروژه
- پس‌زمینه گرافیکی فراهوش برای ورود و داشبورد
