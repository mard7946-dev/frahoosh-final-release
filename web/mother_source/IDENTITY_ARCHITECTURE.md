# Frahoosh v15.8 — Identity Context Refactor

این نسخه برای کاهش خطاهای شناسه ساخته شده است.

- رابط کاربری نباید `teacher_id` یا `student_id` را از کاربر دریافت یا دستی تعیین کند.
- ورودی پنل‌ها باید حساب کاربری/username احراز‌شده باشد.
- تبدیل حساب به رکورد دبیر یا دانش‌آموز فقط در `services/data_link_service.py` انجام می‌شود.
- `services/identity_context.py` مرجع واحد هویت جاری را فراهم می‌کند.
- کلیدهای اصلی SQLite (`id`) حذف نشده‌اند؛ آنها فقط کلید داخلی دیتابیس هستند.
- این تغییر برای جلوگیری از شکست پنل‌ها به علت IDهای گم‌شده، NULL یا ناسازگار است.
