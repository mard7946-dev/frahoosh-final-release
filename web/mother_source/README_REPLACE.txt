فراهوش - پنل دبیر v1

مسیر جایگزینی:
pages/teacher/panel.py

این نسخه هنگام اجرا جداول موردنیاز پنل دبیر را خودکار ایجاد/تکمیل می‌کند و از school.db اصلی پروژه استفاده می‌کند.

امکانات عملیاتی:
- کلاس‌های اختصاص داده شده
- حضور و غیاب و ثبت در attendance
- ثبت نمرات با اتصال به teachers/students/grades
- تکالیف با اتصال به teacher_id
- آزمون آنلاین، ساخت آزمون، لینک اشتراک خارجی و زمان‌بندی چند کلاس
- کلاس مجازی و فعال‌سازی جلسه تاییدشده
- طرح درس و سازگاری با جدول قدیمی lesson_plans
- گزارش عملکرد

تست‌ها:
- Python compile کل 363 فایل غیر از .venv: موفق
- تست عملی SQLite برای کلاس، نمره، آزمون، لینک، زمان‌بندی و طرح درس: موفق
- اجرای GUI در این محیط قابل انجام نبود چون PySide6 باینری پروژه مخصوص Windows است؛ کد با همان PySide6 پروژه سازگار نگه داشته شده است.
