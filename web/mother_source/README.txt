Frahoosh Teacher Panel v1
Drop-in replacement: copy Noura/teacher over the existing Noura/teacher directory.

Implemented:
- teacher-scoped classes
- assignments CRUD
- grades entry/storage
- online quiz creation
- external quiz token generation
- question bank CRUD
- virtual class start/end and capacity setting (700)
- parent meeting requests
- discipline records
- lesson plans
- calendar/report/profile
- database migrations are automatic

Runtime requirement: Python + PySide6. The host project must already provide PySide6.
